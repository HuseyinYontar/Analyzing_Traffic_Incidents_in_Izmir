# Analyzing Traffic Incidents in Izmir

## Dataset
Vehicle malfunction and accident records in İzmir obtained from [ULASAV Open Data Portal](https://ulasav.csb.gov.tr/dataset/35-izmir-ili-arizali-kazali-arac-verileri).

## Weather Data
Daily weather observations for *Gaziemir* and *Çiğli* were collected from [Wunderground](https://www.wunderground.com/) to get past weather information data. [[Gaziemir](https://www.wunderground.com/history/daily/tr/gaziemir/LTBJ/date/2025-9-29), [Çiğli](https://www.wunderground.com/history/daily/tr/%C3%A7i%C4%9Fli/LTBL/date/2025-9-29)]
